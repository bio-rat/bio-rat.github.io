ChefNMR2 — structure from NMR peaks

ChefNMR2 (Xiong et al., 2026, bioRxiv) elucidates the planar structure of a small molecule from its ¹H and ¹³C peak lists and molecular formula. It draws many samples and ranks the structures by how often they occur; that sampling frequency is the model's confidence.

      About this page

      A static page served by GitHub Pages. GitHub Pages cannot run a model or use a GPU, so the demo sends your input to the ChefNMR2 authors' public GPU Space and draws the answer in your browser (2D structures are drawn locally with RDKit.js; the ChemDraw export and the interactive 3D view are built in your browser with OpenChemLib and 3Dmol.js).

      ChefNMR2 code is MIT-licensed; its checkpoints are under CDLA-Sharing-1.0 and were trained on data that include NPAtlas and NP-MRD (CC BY-NC 4.0), so check those terms before any commercial use. Predictions are hypotheses to be checked against the spectra, not proof of a structure.
